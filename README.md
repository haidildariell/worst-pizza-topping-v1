# The Worst Pizza Topping

One funny line pitching a terrible pizza topping, written for the make.fun bounty [The Worst Pizza Topping](https://make.fun/bounty/u-motasimfuad-the-worst-pizza-topping-062c6893).

Our pizza comes topped with wet cardboard — it folds like a love letter, and the box it arrived in is technically the second topping.
